# Changelog

All notable user-visible changes to the Lyrion Music Server TOS application package.

## 9.1.1-1 — 2026-11-12

### Added
- First release. Lyrion Music Server (`lmscommunity/lyrionmusicserver:9.1.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8106 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/lyriondocker/`.
